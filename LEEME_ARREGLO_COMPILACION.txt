REMOCONTROL MOBILE MODERNO - ARREGLO DE COMPILACIÓN

Esta aplicación es únicamente para teléfono, por eso el proyecto móvil ahora compila solo:
- net10.0-android
- net10.0-ios

Se eliminó el target de Windows del proyecto móvil. RemoControl PC es el proyecto separado de Windows.

También se corrigió MainPage.xaml.cs para que BtnHerramientas_Clicked quede dentro de MainPage.

PASOS EN VISUAL STUDIO:
1. Extrae este ZIP en una carpeta NUEVA.
2. Abre RemoControlMobile.slnx.
3. Abre Terminal / Developer PowerShell.
4. Ejecuta: dotnet restore
5. Selecciona Android como destino (no Windows Machine).
6. Compilar > Limpiar solución.
7. Compilar > Recompilar solución.

Para APK usa Release + Android.
